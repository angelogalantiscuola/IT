# Piano di Lavoro: Modulo 00 - Architettura di Sistema e Visione Globale

## 1. Obiettivi di Apprendimento

### Prerequisiti
- Competenze acquisite in 3ª (programmazione procedurale, funzioni, liste, dizionari, file JSON/CSV, testing con Pytest).

### Competenze in Uscita
Al termine di questo modulo introduttivo, lo studente sarà in grado di:
- Salire di livello di astrazione: guardare a un sistema software dalla "vista aerea" prima di toccare i dettagli.
- Applicare il **C4 Model - Livello 1 (System Context)** per mappare utenti e sistemi esterni/API.
- Applicare il **C4 Model - Livello 2 (Container)** per comprendere i confini architetturali (Frontend, Backend Python, Database, Servizi Cloud/AI).
- Tradurre i bisogni degli utenti in **User Stories** concise (*Chi / Cosa / Perché*) corredate da criteri di accettazione verificabili.
- Comprendere la collocazione del lavoro di 4ª all'interno del ciclo di vita del software.

---

## 2. Contenuti Teorici e Metodologici

- **Lezione 01:** `01_Mappa_Concettuale_Architettura.md`
  - Panoramica a 3 colonne dell'approccio architetturale.
- **Lezione 02:** `02_Visione_di_Sistema_C4_Model.md`
  - Dai singoli script alla mappa del sistema: System Context (L1) e Container (L2) con metafore del mondo reale.
- **Lezione 03:** `03_Dalle_User_Stories_ai_Requisiti.md`
  - Dalla richiesta del committente alla User Story: definire cosa deve fare il sistema prima di modellarlo.

---

## 3. Metodologie di Valutazione
- Capacità di disegnare in formato Mermaid un diagramma C4 (Context e Container) per un'applicazione nota (es. un sistema di prenotazione o e-commerce).
- Stesura di 3-4 User Stories coerenti e complete di criteri di accettazione partendo da uno scenario di testo.
